# 💰 Personal Finance & Expense Tracker

> **Track your money. Understand your spending. Build better financial habits.**

A full-stack **Personal Finance & Expense Tracker** designed to help users manage their daily income and expenses through a clean, interactive dashboard.

The project is built using **Java Spring Boot** for the backend, **MySQL** for data storage, and **Flutter** for the cross-platform frontend.

It demonstrates real-world full-stack development concepts including REST APIs, database management, CRUD operations, JPA/Hibernate, state management, API integration, and financial data visualization.

---

## 📸 Project Overview

The application provides a centralized dashboard where users can:

- View total income
- View total expenses
- Check current balance
- Add income and expenses
- Edit existing transactions
- Delete transactions
- View transaction history
- Categorize transactions
- Analyze spending patterns
- View financial charts and trends

---

## 🚀 Features

### 📊 Financial Dashboard

The dashboard provides an overview of the user's financial activity.

It displays:

- 💵 Total Income
- 💸 Total Expenses
- 💰 Current Balance
- 📈 Monthly financial trends
- 🥧 Category-wise expense distribution
