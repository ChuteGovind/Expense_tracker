# Developer Guide

Backend packages:
- `entity` — JPA models
- `repository` — database access
- `service` — business logic and dashboard aggregation
- `controller` — REST API
- `dto` — API payloads
- `config` — CORS

Frontend packages:
- `models` — JSON models
- `services` — Dio API client
- `providers` — Riverpod state
- `screens` — pages
- `widgets` — reusable UI
- `core` — API URL and theme
